Focused Feedback (2 Priority Corrections)

B1 → B2 Target Upgrade
1. Comparative Degree GRAMMAR
more fast ➔ faster / significantly faster

One-syllable adjectives take -er. To add emphasis, use significantly / much faster.

2. Literal Slavicism / Natural Collocation SLAVICISM
the minus was that... ➔ the main drawback / trade-off

In Ukrainian/Russian, "минус" is common for a disadvantage. In native English, prefer the main drawback or the trade-off.

⭐ Recommended B2 Phrasing to Re-Speak:

“We opted for gRPC because it was significantly faster. However, the main drawback was the steeper debugging curve for junior engineers.”
